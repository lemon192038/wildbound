# Wildbound — module contracts

Original monster-hunting co-op action game in Three.js (r187, `import * as THREE from 'three'`, addons via `three/addons/...`).
All IP is ORIGINAL: no names, monsters, characters, UI art, music or sounds from any existing game.

`game` (built in src/main.js) is passed to every factory. Fields:
`THREE, engine, scene, camera, renderer, events, input, params, monsters[], remotePlayers(Map), world, player, cameraRig, audio, ui, net, time, addUpdater(fn)`.
`engine.hitstop` (seconds), `engine.timeScale`, `engine.post`.
Game loop order per frame: world.update(dt,rawDt) → player.update(dt,input,rawDt) → monsters[i].update(dt,rawDt) → updaters → cameraRig.update(rawDt,input) → net.update → audio.update → ui.update → render.
dt is 0 during hitstop; use rawDt for things that should keep moving (camera, particles optional, UI).

## Ownership (one agent per folder — do NOT edit other folders; ask via report instead)
| Folder | Owner | Factory / interface |
|---|---|---|
| src/world/ | World agent | `createWorld(game) -> Promise<{update(dt,rawDt), getHeight(x,z), getNormal(x,z), bounds:{radius}, sun: DirectionalLight, spawn:{player:Vector3, monster:Vector3}, colliders:[{x,z,r}], spawnDust(pos, amount), spawnSplash(pos)}>`; `createPost(game) -> {render(), setSize(w,h)}` |
| src/monster/ | Monster agent | `createMonster(game) -> Promise<{update(dt,rawDt), object3d, position(Vector3), hp, maxHp, name, parts:[{name, hp, broken, hitzone:number(dmg multiplier)}], state, getHitboxes() -> [{part, sphere:Sphere}], getAttackHitboxes() -> [{sphere, damage, knockback}], receiveHit({damage, part, point, normal, attackerId}), serialize(), applyRemote(state)}>` |
| src/player/ | Player agent | `createPlayer(game) -> Promise<{update(dt,input,rawDt), object3d, position, facing(rad), hp, maxHp, stamina, maxStamina, sharpness, state, lockTarget, receiveHit({damage, knockback, from:Vector3}), serialize(), id}>`; `createCameraRig(game) -> {update(rawDt,input), shake(i,d)}`; also exports `createRemoteHunter(game, id)` -> {object3d, applyRemote(state), dispose()} |
| src/net/ + server/ | Net agent | `createNet(game) -> {update(dt,rawDt), connected, id, roomPlayers}`; server/server.js: ws server + serves dist/ statically on PORT (default 8080). Client connects only if `?online=1` or to same-origin `/ws`; offline must work flawlessly. |
| src/ui/ | UI agent | `createUI(game) -> {update(dt,rawDt), toast(text)}` DOM HUD in #ui-root |
| src/audio/ | Audio agent | `createAudio(game) -> {update(dt,rawDt), play(name, pos, vol)}` procedural WebAudio only (no asset files), unlocks on first user gesture |

## Combat flow
Player computes its weapon hit spheres during active frames, intersects with `monster.getHitboxes()`, calls `monster.receiveHit(...)` once per swing per part, and emits `events.emit('hit', {...})` + `'hitstop'` + `'camera:shake'`.
Monster checks `getAttackHitboxes()` vs player position (capsule radius 0.5, height 1.8) itself and calls `player.receiveHit` (respect player i-frames: player.receiveHit returns false if invulnerable).
Events: see src/core/events.js header.

## Assets
No external downloads at runtime. Procedural geometry/textures (canvas, DataTexture, shaders) or files committed under public/ generated by our own scripts.
Performance target: 60fps at 1080p on a mid-range GPU; headless Chromium (SwiftShader) must still render a frame without crashing.

## Debug hooks (keep working)
`window.__game`, `window.__ready`. URL params: `?shot=1` (skip intro, deterministic), `?cam=x,y,z,tx,ty,tz` (fixed camera for screenshots), `?online=1`.

## Town (hub) mode — added for the city update
`?mode=town` (default when no quest/hunt param). main.js `bootTown()` loads `src/town/town.js` and `src/town/townHud.js`.
`createTown(game) -> Promise<{ update(dt,rawDt), getHeight(x,z), getNormal(x,z), bounds:{radius}, sun, colliders:[{x,z,r}],
  spawn:{player:Vector3, monster:Vector3}, spawnDust(pos,amount), spawnSplash(pos), dispose(),
  interactables:[{ id:'quest'|'smith'|'alchemy'|'shop'|'storage'|'dock', name, npc, position:Vector3 (where the player stands to talk), radius, npcObject?:Object3D }] }>`
- Same world interface the existing player/camera already use (getHeight drives the hunter's feet; colliders are circles).
- `game.peaceful = true` in town; the HUD/panels (src/town/townHud.js, src/ui/panels/) belong to the main developer.
- Owner of src/town/ (except townHud.js): Town builder agent.
